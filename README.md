This project was done in 2023, I've now updated it to have a downloadable .nds file and it now compiles on the latest version of devkitpro.

## Build:
This demo has been updated to use [devkitPro 3.3](https://devkitpro.org) (devkitARM + libnds + maxmod) to produce a `.nds` ROM.
enter the directory and run
```bash
make clean
make
```
